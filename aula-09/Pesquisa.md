# Atividade Prática - Objetos e Classes

## 1. O que é um objeto em programação?
Um objeto é uma forma de guardar informações relacionadas em um só lugar.

## 2. O que é uma propriedade de um objeto? Cite um exemplo.
Uma propriedade é uma informação que pertence ao objeto.
Exemplo:
```javascript
let aluno = {
    nome: "Ana"
}
```
Nesse exemplo, "nome" é uma propriedade.

## 3. O que é um método? Qual a diferença entre método e propriedade?
Um método é uma função que fica dentro de um objeto ou classe.
A diferença é que a propriedade guarda informações, enquanto o método faz alguma ação.

## 4. O que é uma classe?
Uma classe é um modelo usado para criar objetos.

## 5. Qual a diferença entre classe e objeto?
A classe é o modelo e o objeto é algo criado a partir desse modelo.
Por exemplo, uma classe Carro pode ser usada para criar vários carros diferentes.

## 6. Para que serve o constructor dentro de uma classe?
O constructor serve para definir os valores iniciais do objeto quando ele é criado.

## 7. O que significa a palavra this dentro de uma classe?
A palavra this serve para acessar as propriedades e métodos do próprio objeto.

## 8. O que a palavra new faz ao criar um objeto?
A palavra new cria um novo objeto usando uma classe.

## 9. Em TypeScript, por que usamos tipos como string, number e boolean?
Usamos esses tipos para indicar qual tipo de dado será armazenado.
- string = texto
- number = número
- boolean = verdadeiro ou falso

Um exemplo seria a classe Aluno.
Propriedades:
- nome

- turma

Método:
